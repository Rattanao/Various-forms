Check EDI — ENTER ชุดรวมหลายฟอร์ม

เทียบ MF (MANIFEST) กับ ENTER ที่เป็น PDF ไฟล์เดียวรวมหลายฟอร์ม → รายงาน EDI.xlsx แบบใส่สี

ดาวน์โหลด

ดาวน์โหลดโปรแกรม (ZIP) ดูใน GitHub

โปรแกรมรันบนเครื่อง Windows 10/11 (ใช้ OCR ของ Windows อ่านหน้าสแกน) — ไฟล์ลูกค้าไม่ถูกอัปโหลดไปที่ใด

ติดตั้งครั้งแรก

  1. ติดตั้ง Python 3.10+ จาก python.org — ติ๊ก Add python.exe to PATH
  2. แตกไฟล์ ZIP ไว้ที่ไหนก็ได้
  3. ครั้งแรกที่รัน โปรแกรมติดตั้งไลบรารีที่ต้องใช้ให้เอง

ใช้งาน

  1. วาง MF (.xls / .xlsx / .pdf) และ ENTER (.pdf) ในโฟลเดอร์ input
  2. ดับเบิลคลิก run-check-edi.bat
  3. ใส่ SHED NO. เลขเดียวทุก B/L (เช่น 0141) หรือแยก LCL/CFS กับ CY (เช่น 0141 / 0121)
  4. รายงานอยู่ที่ output\EDI-<วันเวลา>.xlsx

อ่านรายงาน

  • แดง = ไม่ตรง
  • ส้ม = ต้องให้คนตรวจยืนยัน (รวมหน้าที่อ่านด้วย OCR)
  • เหลือง = ไม่มี ENTER ให้เทียบ
  • เขียว = ผ่าน

ลงผลเฉพาะ B/L ที่มีใน ENTER · หมายเหตุบอกหน้า ENTER ที่อ่าน [ENTER หน้า n] · B/L แตกเรียงต่อกัน

ฟอร์มที่อ่านได้

ARRIVAL NOTICE / สำเนา B/L + ATTACHED RIDER, หน้าสแกน (OCR), จดหมายแก้ไขของ forwarder หลายสิบแบบ (ตาราง AMENDMENT, LEO GLOBAL, KUEHNE + NAGEL, GENIUS, SHIP MASTER, MAXTOP, NIPPON, SINTOP ฯลฯ) และฟอร์มของ forwarder ที่มีตัวอ่านเฉพาะ (Sinotrans, LX Pantos, Freight Links, Shipco, Planet, Union World, AGN, Handle Inter, Able, Quality, MAC-NELS, CMS / M INTER, DSV)
